    switch(op) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/': return a / b;

🧠 این دستیار هوشمند چطور کار می‌کنه؟

۱

ثبت نام سریع و آسان

فقط با یه ایمیل یا شماره موبایل، حساب خودت رو بساز و بلافاصله شروع کن. اطلاعاتت پیش ما محفوظ می‌مونه و پروژه‌هات همیشه در دسترس هستن.

۲

سنجش تطبیقی هوشمند

با ۵ سوال هدفمند، سطح واقعی برنامه‌نویسی تو رو تشخیص می‌دیم. سوال‌ها بر اساس پاسخ‌هات سخت‌تر یا آسون‌تر می‌شن تا دقیق‌ترین نتیجه رو بگیریم.

۳

انتخاب ایده یا نمونه‌کار

از بین ده‌ها نمونه‌کار آماده (ماشین حساب، لیست کارها، فروشگاه و...) انتخاب کن یا ایده خودت رو بگو تا برات بسازیمش.

۴

ساخت گام‌به‌گام با هوش مصنوعی

پروژه‌ات رو قدم‌به‌قدم با کمک هوش مصنوعی می‌سازیم. هر قدم رو تأیید کن، تغییر بده یا سوال بپرس. همه چی تحت کنترل توئه.

۵

پیش‌نمایش زنده و تست خودکار

همون لحظه خروجی کارت رو ببین. سیستم خودکار کدت رو تست می‌کنه و قبل از تحویل نهایی، خطاها رو پیدا می‌کنه.

۶

تحویل و ذخیره

پروژه نهایی رو با README و راهنمای اجرا تحویل بگیر. دانلود کن، ذخیره کن یا بعداً برگرد و ادامه بده.
